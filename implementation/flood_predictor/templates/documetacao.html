Documentação da API Nvula

O modelo foi integrado a uma API Flask para permitir consultas programáticas e alimentação da interface web.

Principais endpoints:

  • POST /api/predict

    Descrição: recebe dados meteorológicos e retorna a probabilidade de inundação.

    Entrada (JSON):

    { "precipitacao": 120.5, "umidade": 75.2, "temperatura": 28.4, "provincia": "Luanda" }

    Saída (JSON):

    { "provincia": "Luanda", "probabilidade_inundacao": 0.82, "risco": "Alto" }
  • GET /api/provincias

    Descrição: retorna uma lista de províncias e seus riscos de inundação calculados automaticamente.

    Saída (JSON):

    [ {"provincia": "Luanda", "risco": "Alto"}, {"provincia": "Benguela", "risco": "Médio"}, {"provincia": "Huambo", "risco": "Baixo"} ]
Considerações de Segurança
  • Criptografia HTTPS: todas as comunicações entre cliente e servidor ocorrem via HTTPS.
  • Isolamento do modelo: o arquivo do modelo não é exposto; apenas previsões são retornadas.
  • Sanitização de entradas: todas as requisições são validadas antes do processamento.
  • Autenticação básica (futura): será implementada via tokens JWT.
  • Controle de logs: os logs não armazenam dados sensíveis enviados pelos usuários.
